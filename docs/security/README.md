# docs/security/ — 安全工件与结论

## 必须归档的内容

| 工件 | 频率 | 判据 |
| --- | --- | --- |
| 密钥明文扫描报告 | 每个 PR（CI）+ 每个 Gate（全量） | 命中数 = 0 |
| SBOM | 每次构建 | 存在且覆盖传递依赖 |
| 许可证清单与白名单校验 | 每个 PR | 零黑名单命中 |
| 依赖漏洞扫描 | 每阶段 | 无 Critical/High 未处置 |
| 可复现构建对照 | 每次发布 | 哈希相同或原因清单完整 |
| 暴露面清单核查记录 | 每个 Gate | ADR-002 §4 的 10 项逐项有结论 |
