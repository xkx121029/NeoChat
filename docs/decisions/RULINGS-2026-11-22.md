# RULINGS-2026-11-22 — 人类裁决记录

> 本文件逐字保留人类在 2026-11-22 对五个硬冲突的裁决。ADR 的修改必须以本文件为依据；本文件不可被后续 ADR 覆盖，只可被新的裁决记录取代。

原始裁决（逐条）：

1. **Windows 启动拆三档**：首帧可见 ≤0.9s / 首屏可交互 ≤1.2s / 托盘唤起 ≤120ms，各配地板线；注明单数字不可归因，NativeAOT 只作加分项。
2. **视觉等价改三层**：模型层与结构层均要求 0 差异（CI 断言），视觉层 Android ≤2dp / Windows ≤2px；行为等价改由交互脚本回归。
3. **密钥互通只走口令导出**：设备内 Keystore/DPAPI 密文不可跨机复制；跨设备用口令 + Argon2id + AES-256-GCM，明写“每次导出多输一次口令”为接受代价。
4. **流式仅前台保证**：后台挂起合法，回前台提示可续传，UI 两处明示；前台服务+常驻通知列为 v2 且本期不许做半个。
5. **Mermaid 只做 flowchart/sequence**：静态、无动画、其余降级为代码块+明示，禁用“尽力支持”。

## 我（Tech Lead）落地时的两处解释，已写进 ADR；若不认可请纠正

1. 裁决 4 的“续传”落地为**客户端续写**：以已生成内容为上下文发起一次新的助手消息。理由：OpenAI / Anthropic / Gemini / OpenRouter 均无流式断点续传接口，provider 级续传在 v1 不可能实现。文案写“继续生成”，不写“恢复连接”。
2. 裁决 2 的“行为等价改由交互脚本回归”落地为 **L4 层**（12 条脚本），与 L1~L3 并列而非替代 L3——截图仍负责捕获纯视觉回归，脚本负责捕获“看起来对但点不动”。
