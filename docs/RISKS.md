# docs/RISKS.md — 风险登记册

每条风险都预先决定应对，不临场发挥。触发信号一旦出现，按"应对"列执行，并当轮上报人类（准则 8）。

| # | 风险 | 触发信号 | 应对（预先决定） | 等级 |
| --- | --- | --- | --- | --- |
| R1 | WinUI 3 与 NativeAOT 不兼容 | AOT 编译失败 / 反射相关崩溃 | 放弃 AOT，走 R2R + 单文件不裁剪；ADR-001 §2.5 已记录性能影响 | 已确认，降级为已知限制 |
| R2 | Windows 首帧 / 可交互达不到三档线 | 两轮实测超出地板（首帧 >1.2s 或 可交互 >1.6s） | 已按人类裁决拆三档（ADR-001 §2.5）；仍不达标则依次检查 XAML 预编译、延后初始化、托盘预热、运行时自包含方式 | 中 |
| R3 | 无 WebView 时 Mermaid 失控 | 大图卡死 / 布局错乱 / 超 200ms | 只做 flowchart + sequence；超限降级代码块；禁止把 WebView 引回主路径 | 中 |
| R4 | 渲染性能不达标（长消息滚动掉帧） | 帧耗时 P99 > 16ms | 增量解析 + AST 缓存 + 视口懒渲染 + 分段渲染；仍不达标则 ADR 记录取舍并功能降级 | 高 |

| R6 | MCP stdio 进程管理（Windows） | 僵尸进程 / 管道阻塞 / 退出码丢失 | 超时 + 强制 kill + 输出上限 + 异常兜底，列为独立验收项（M4） | 中 |
| R7 | 各家 API 频繁变更 | 某 provider 突然 400 / 字段改名 | 模型元数据全可编辑；错误透传脱敏原始响应；provider 级 `pass_through` 逃生舱 | 高 |
| R8 | Android 后台被杀导致长任务中断 | 切后台后流式中断 | **已裁决**：流式仅前台保证，后台挂起合法；回前台两处明示 + “继续生成”（客户端续写，非续传）；悬挂流启动时修复为 aborted；前台服务 + 常驻通知列 v2，本期不许做半个 | 已接受 |
| R9 | 执行者虚报完成 | 报告"已完成"但无命令输出 | 抽检 ≥40%，无输出不签收；连续两次虚报则更换任务拆分方式并降低任务粒度 | 中 |
| R10 | 顶级标准导致范围失控 | 任务单越拆越多、里程碑持续延期 | 触发三角重算，强制人类重选范围/时间/质量 | 高 |
| R11 | spec 漂移 | 两端实现出现未记录差异 | 全量 conformance + diff 定位 + 补 spec 缺漏并升版本 | 中 |
| R12 | 依赖供应链风险 | 某依赖停维护 / 爆漏洞 | 锁版本 + SBOM + 每阶段漏洞扫描；关键路径自研替代预案（PDF 抽取、分词器、Mermaid 布局） | 中 |
| R13 | 密钥泄露于第三方中转 | 用户配置了不规范 Base URL | 明确提示风险；不内置任何中转；诊断页检测可疑 Base URL 并警告 | 中 |
| R14 | 无障碍返工冲击晚期 | M7 才发现 TalkBack 断裂 | 每个 UI 任务单强制含无障碍验收项；M1 起每个 UI PR 交付 TalkBack 录屏 | 中 |
| R15 | i18n 返工冲击晚期 | 晚期发现硬编码 | CI 从 M0 起强制零硬编码检查 | 低 |

| R18 | **（本项目特有）** PDF 抽取包体与性能冲突 | Android 包体 > 25MB 且 50 页抽取 > 2.5s | 评估轻量库（PdfBox-Android / 自研文本层抽取）；超限则 PDF 解析改为可选下载模块 | 中 |
| R19 | **（本项目特有）** Windows 全局热键取不到其他应用选中文本 | UIPI / 权限阻止 UI Automation | 降级为"剪贴板 + 热键"两步路径，UI 说明；不申请提权 | 中 |
