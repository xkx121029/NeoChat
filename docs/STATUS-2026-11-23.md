## 5 怎么跑

**Windows**（本机已验证）：
```powershell
$env:NEOCHAT_BASE_URL='http://127.0.0.1:8787/v1'; $env:NEOCHAT_MODEL='mock-chat'; $env:NEOCHAT_API_KEY='mock-no-auth'
python tools/demo/mock_openai_sse.py 8787
& 'windowsApp\NeoChat.Windows\bin\Release\net9.0-windows10.0.26100.0\win-x64\NeoChat.Windows.exe'
```
构建：`~/dotnet9/sdk/dotnet.exe build windowsApp/NeoChat.Windows/NeoChat.Windows.csproj -c Release -p:EnableCoreMrtTooling=false`

**演示重录**：`powershell -NoProfile -ExecutionPolicy Bypass -File tools\demo\capture_demo.ps1`
产物：`docs/reviews/media/M1-WIN-demo.gif`（34 帧 / 6 秒）

**Android**：`gradle :androidApp:app:assembleDebug`（`local.properties` 里 `sdk.dir` 指向 `~/AppData/Local/Android/Sdk`）
